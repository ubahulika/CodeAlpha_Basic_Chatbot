 🤖 Basic ChatBot using Python
 📌 Project Overview
This project is a simple rule-based chatbot developed using Python.  
The chatbot interacts with users through predefined responses based on user input.
🚀 Features
1. Greets the user
2. Responds to simple questions
3. Handles unknown inputs
4. Exit option to end the chat
🛠️ Technologies Used
1. Python
2.Conditional Statements
3. Loops
4. Functions
5. Input/Output Handling

 ▶️ How to Run
1. Install Python on your system
2. Save the code as chatbot.py
3. Open terminal or command prompt
4. Run the file using:python chatbot.py
